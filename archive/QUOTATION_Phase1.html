4. EXCLUDED COSTS (CLIENT RESPONSIBILITY)

The following are required for the website to function but are not included in the development fee:

Domain Registration R 150 – R 300 per year
The domain is the website address (e.g., www.yourfirm.co.za). This must be renewed annually to keep the website active.
Web Hosting R 70 – R 150 per month
Hosting is the online server where all website files and data are stored. This ensures the website is accessible 24/7 to users.
SSL Certificate Included with most hosts / R 50–100/year
Secures website data and shows customers the site is trusted.
Maintenance & Support Optional - R 500–1,500/month
Future updates, backups, security monitoring, and technical support.
